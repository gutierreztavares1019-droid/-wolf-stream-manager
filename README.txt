WOLF STREAM Manager — prototipo PWA
========================================
Incluye:
- Dashboard
- Cuentas y cálculo automático de perfiles libres/ocupados
- Clientes
- Renovaciones y días restantes
- Respaldo/restauración JSON
- Diseño responsive para teléfono
- Branding WOLF STREAM a partir del logo proporcionado

Para usarlo en un teléfono:
1. Sube esta carpeta a un hosting estático con HTTPS (por ejemplo GitHub Pages, Netlify o Vercel).
2. Abre la dirección desde Safari/Chrome.
3. En iPhone: Compartir -> Añadir a pantalla de inicio.
4. En Android: menú del navegador -> Instalar aplicación.

Importante:
Esta primera versión guarda los datos en el navegador del dispositivo. Para una versión de producción conviene añadir inicio de sesión y una base de datos segura antes de almacenar credenciales reales.
